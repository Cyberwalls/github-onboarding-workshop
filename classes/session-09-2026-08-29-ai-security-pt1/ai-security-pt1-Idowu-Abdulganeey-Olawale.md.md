## Key Concepts I Learned

* AI workloads introduce new security risks involving AI agents, identities, data, applications, models, and runtime activities.

* Microsoft Entra Agent ID provides a way to manage identities for AI agents, while Conditional Access can help control how and when agents access resources.

* Microsoft Defender XDR can help security teams discover AI agents, identify risks associated with their identities, and investigate potential attack paths.

* Microsoft Defender for Cloud Apps provides visibility and protection for AI applications, including agents created with Copilot Studio.

* AI Gateway in Microsoft Foundry can help organizations secure, manage, and monitor traffic between applications and AI models.

* Microsoft Foundry guardrails can help protect AI applications by evaluating prompts and responses and applying content filtering and other safety controls.

* Microsoft Defender for Cloud helps organizations identify security weaknesses and protect AI workloads against threats during runtime.

* Microsoft Purview Data Security Posture Management (DSPM) for AI helps organizations identify and manage data security risks associated with AI usage.

* Microsoft Agent 365 provides capabilities for registering, managing, monitoring, and governing AI agents across an organization.

* AI security requires a layered approach, combining identity protection, access control, data security, guardrails, monitoring, governance, and runtime protection.

### My Takeaways

**My main takeaway from these modules was that AI security requires a layered and continuous approach*.

* I learned that securing an AI model alone is not enough. AI agents can have identities, access organizational data, interact with applications, call external tools, and perform actions on behalf of users.

* I found the concept of least privilege for AI agents particularly useful because agents should only have access to the resources and permissions required to perform their intended tasks.

* I also learned that guardrails, monitoring, and runtime protection are important because AI systems can be exposed to new threats such as malicious prompts, unauthorized access, data exposure, and manipulation of AI agent behavior.

* The lab demonstration helped me connect the theoretical concepts from the Microsoft Learn modules with how these security controls can be applied in a real Microsoft environment.
